# PRD.md — Karasu Buyers Club

**نسخه سند:** 1.0.0
**نوع افزونه:** WordPress / WooCommerce Plugin (مستقل)
**وابستگی الزامی:** WooCommerce (نسخه‌های دارای پشتیبانی HPOS)
**زبان اصلی محصول:** فارسی (RTL) — ساختار آماده i18n

---

## ۱. بیانیه مسئله (Problem Statement)

فروشگاه‌های ووکامرسی فارسی‌زبان معمولاً به یکی از این دو مشکل دچارن:
1. افزونه‌های باشگاه مشتریان خارجی (مثل WooCommerce Points and Rewards) که با درگاه‌های پیامکی ایرانی، تقویم شمسی و نیازهای بومی سازگار نیستن.
2. راهکارهای داخلی که ناقص، ناامن، یا فاقد معماری مقیاس‌پذیر (React/REST API) هستن.

Karasu Buyers Club قراره این خلأ رو با یک افزونه مستقل، امن، و کاملاً بومی‌سازی‌شده پر کنه.

---

## ۲. اهداف پروژه (Goals)

| # | هدف |
|---|------|

| G2 | پیاده‌سازی سیستم سطح‌بندی مشتریان (Tiers) بدون تنزل، بر اساس ارزش کل خرید دوره عضویت |

| G8 | سازگاری کامل با HPOS و ساختار داده‌ای مقیاس‌پذیر (جداول اختصاصی، نه متا دیتای پراکنده) |

## ۳. مخاطب هدف (Target Users)

- **مدیر فروشگاه (Admin):** صاحبان فروشگاه‌های ووکامرسی فارسی‌زبان که می‌خوان بدون نیاز به دانش فنی، باشگاه مشتریان راه‌اندازی کنن.
- **مشتری نهایی (Customer):** خریداران فروشگاه که امتیاز کسب می‌کنن، سطح ارتقا می‌گیرن، و از پاداش‌ها استفاده می‌کنن.
- **توسعه‌دهنده/پیاده‌ساز (در نسخه‌های آتی):** کسانی که افزونه رو روی فروشگاه‌های مشتری نصب و سفارشی‌سازی می‌کنن.

## ۴. لیست دقیق قابلیت‌ها (Features)

### ۴.۱ موتور امتیازدهی (Points Engine)
- [ ] امتیازدهی بر اساس مبلغ خرید با نرخ تبدیل قابل تنظیم (عمومی + اختصاصی per دسته/محصول)
- [ ] امتیازدهی بر اساس اکشن: ثبت‌نام، اولین خرید، ثبت نظر، تکمیل پروفایل، عضویت خبرنامه
- [ ] معماری Hook-based برای افزودن اکشن‌های جدید بدون تغییر ساختار دیتابیس
- [ ] انقضای امتیاز قابل فعال/غیرفعال از پنل ادمین، با منطق FIFO و یادآوری پیش از انقضا
- [ ] تاریخچه کامل تراکنش‌های امتیاز (کسب/مصرف/انقضا) قابل مشاهده برای مشتری و ادمین

### ۴.۲ مصرف امتیاز (Redemption)
- [ ] تبدیل امتیاز به کد تخفیف (یکبارمصرف یا درصدی)
- [ ] تبدیل امتیاز به ارسال رایگان
- [ ] تبدیل امتیاز به هدیه (محصول انتخابی از لیست تعریف‌شده)
- [ ] تبدیل امتیاز به شارژ کیف‌پول
- [ ] فعال/غیرفعال‌سازی هرکدام از مسیرهای بالا + نرخ تبدیل، از پنل ادمین

### ۴.۳ کیف پول داخلی (Wallet)
- [ ] موجودی کیف‌پول مجزا از امتیاز
- [ ] بدون قابلیت برداشت نقدی — فقط قابل استفاده در چک‌اوت به‌عنوان روش پرداخت جزئی/کامل
- [ ] تاریخچه تراکنش‌های کیف‌پول
- [ ] پیاده‌سازی به شکل سازگار با گزارش مالی ووکامرس (Fee/Coupon، نه دستکاری مستقیم قیمت)

### ۴.۴ سیستم سطح‌بندی (Tiers)
- [ ] تعریف تعداد و نام سطوح دلخواه توسط ادمین
- [ ] ارتقا بر اساس مجموع خرید کل دوره عضویت (Lifetime Value)، بدون تنزل
- [ ] مزایای اختصاصی هر سطح: ضریب امتیازدهی، تخفیف اختصاصی، ارسال رایگان خودکار، هدیه ارتقا
- [ ] نمایش بصری سطح (بج/آیکون/رنگ) در پروفایل و صفحه باشگاه

### ۴.۵ مناسبت‌های خاص (تولد و سالگرد عضویت)
- [ ] فیلد تاریخ تولد (اختیاری) در پروفایل کاربر با پشتیبانی تقویم شمسی
- [ ] تنظیم پاداش هر مناسبت توسط ادمین: کد تخفیف، امتیاز هدیه، هردو، یا خاموش
- [ ] زمان‌بندی خودکار (Cron) ارسال پاداش نزدیک تاریخ مناسبت

### ۴.۶ معرفی دوست (Referral)
- [ ] کد معرف اختصاصی برای هر مشتری
- [ ] امتیاز برای معرف و معرفی‌شونده (هر دو طرف)
- [ ] تنظیم شرط فعال‌سازی (ثبت‌نام یا اولین خرید) و محدودیت ضد سوءاستفاده
- [ ] گزارش عملکرد معرفی برای هر مشتری

### ۴.۷ اطلاع‌رسانی (Notifications)
- [ ] اتصال به درگاه‌های پیامکی ایرانی: Kavenegar، Mellipayamak، FarazSMS (قابل انتخاب + تنظیم API Key)
- [ ] ایمیل مبتنی بر wp_mail با قالب‌های قابل ویرایش
- [ ] مرکز اعلان داخلی در پنل کاربری React
- [ ] قالب‌های پیام Placeholder-based و قابل ویرایش از پنل ادمین برای همه رویدادها

### ۴.۸ رابط کاربری مشتری (Customer UI)
- [ ] تب اختصاصی داخل My Account (خلاصه وضعیت)
- [ ] صفحه/داشبورد مستقل باشگاه مشتریان (نمای کامل: پیشرفت سطح، تاریخچه، پاداش‌ها، معرفی دوست، اعلان‌ها)
- [ ] طراحی RTL کامل با React + Tailwind

### ۴.۹ پنل مدیریت (Admin Panel)
- [ ] داشبورد آماری کلی
- [ ] تنظیمات امتیازدهی و انقضا
- [ ] مدیریت سطوح
- [ ] مدیریت پاداش‌ها
- [ ] تنظیمات مناسبت‌های خاص
- [ ] تنظیمات معرفی دوست
- [ ] تنظیمات کانال‌های اطلاع‌رسانی و قالب پیام‌ها
- [ ] مدیریت اعضا (جستجو، فیلتر، ویرایش دستی امتیاز/کیف‌پول/سطح)
- [ ] گزارش‌گیری و خروجی Excel/CSV

### ۴.۱۰ یکپارچگی با Elementor
- [ ] ویجت‌های اختصاصی Elementor برای نمایش وضعیت باشگاه، بج سطح، و فراخوان به عمل (CTA) در صفحات دلخواه

## ۵. موارد خارج از محدوده (Out of Scope — نسخه فعلی)

- **بدون قابلیت برداشت نقدی از کیف‌پول** (نه به بانک، نه به درگاه پرداخت)
- **بدون پشتیبانی چندفروشگاهی/چندفروشندگی (Multi-vendor)** در این فاز
- **بدون اپلیکیشن موبایل اختصاصی** — فقط وب/PWA در آینده احتمالی
- **بدون سیستم گیمیفیکیشن پیشرفته** (بج‌های چندلایه، لیدربورد عمومی، چالش‌های زمان‌دار) در نسخه اول
- **بدون یکپارچگی با پیج‌بیلدرهای دیگر به‌جز Elementor** (مثل Divi، Bricks) در این فاز
- **بدون سیستم اشتراک/عضویت پولی (Paid Membership Tiers)** — سطوح فقط بر اساس رفتار خرید هستن، نه پرداخت ورودی
- **بدون چندزبانگی کامل UI در نسخه اول** — فقط ساختار i18n آماده، ترجمه فقط فارسی
- **بدون مارکت‌پلیس پاداش بین فروشگاهی** (پاداش‌ها فقط داخل همون فروشگاه معتبرن)
- **بدون هوش مصنوعی/پیشنهاد شخصی‌سازی‌شده پاداش** در این فاز

---

## ۶. معیارهای موفقیت (Success Criteria)

- نصب و راه‌اندازی اولیه بدون خطا روی وردپرس + ووکامرس با HPOS فعال
- تمام قابلیت‌های بخش ۴ عملیاتی و تست‌شده
- بدون هیچ‌گونه Kill-switch، تله‌متری پنهان، یا اتصال بیرونی غیرشفاف
- عبور از بررسی امنیتی پایه (Sanitization/Escaping/Nonce) روی تمام نقاط ورودی
- آماده برای فروش/توزیع مستقل (مطابق مدل karasu-woo-pannel)

## ۷. وابستگی‌ها و پیش‌نیازها

- WordPress (آخرین نسخه پایدار)
- WooCommerce (با پشتیبانی HPOS)
- PHP 8.0+
- Node.js + Vite برای بیلد فرانت‌اند (React + Tailwind)
- Elementor (اختیاری — فقط برای فعال‌سازی ویجت‌های اختصاصی)
