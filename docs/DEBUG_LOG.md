## ساختار هر ورودی

هر ورودی باید دقیقاً با این قالب ثبت بشه:

```markdown
## [YYYY-MM-DD HH:MM] — عنوان کوتاه مشکل

**فاز/بخش مرتبط:** (مثلاً فاز ۲ — WalletService)
**نسخه افزونه در زمان بروز:** (مثلاً 0.3.1)

### شرح مشکل
توضیح دقیق رفتار مشاهده‌شده، پیام خطا (در صورت وجود، عیناً کپی‌شده در بلاک کد)، و شرایطی که مشکل رخ می‌ده.

### علت ریشه‌ای (Root Cause)
تحلیل دقیق چرایی وقوع مشکل — نه فقط راه‌حل سطحی.

### راه‌حل اعمال‌شده
توضیح تغییری که داده شد + مسیر فایل(های) تغییریافته.

### درس گرفته‌شده / پیشگیری آینده
یک یا چند جمله که چطور از تکرار این مشکل جلوگیری کنیم (مثلاً افزودن یک قانون به GUIDELINES.md، یا یک تست جدید).

### وضعیت
- [ ] باز
- [ ] در حال بررسی
- [x] رفع‌شده
```

## دسته‌بندی برچسب‌ها (Tags)

هر ورودی باید حداقل یک برچسب از این لیست داشته باشه (در کنار عنوان قابل اضافه‌شدن به‌صورت `#tag`):

| برچسب | حوزه |
|---|---|
| `#database` | مشکلات دیتابیس/Migration/Query |
| `#security` | مسائل امنیتی (Nonce, Sanitization, Escaping, Capability) |
| `#woocommerce` | تداخل یا رفتار غیرمنتظره Hookهای ووکامرس |
| `#hpos` | مشکلات مرتبط با سازگاری HPOS |
| `#rest-api` | مشکلات endpoint ها یا احراز هویت REST |
| `#react` | مشکلات فرانت‌اند/بیلد Vite/Tailwind |
| `#elementor` | مشکلات یکپارچگی ویجت‌ها |
| `#sms` | مشکلات درگاه‌های پیامکی (Kavenegar/Mellipayamak/FarazSMS) |
| `#performance` | کندی/مشکلات مقیاس‌پذیری |
| `#build-release` | مشکلات مربوط به فرآیند بسته‌بندی/زیپ/گیت‌هاب ریلیز |

## نمونه ورودی (Template پرشده — صرفاً جهت الگو، هنگام شروع توسعه حذف بشه)

```markdown
## [2026-08-01 14:30] — عدم اعمال کیف‌پول در چک‌اوت #woocommerce #database

**فاز/بخش مرتبط:** فاز ۲ — CheckoutWalletGateway
**نسخه افزونه در زمان بروز:** 0.2.4

### شرح مشکل
هنگام انتخاب «استفاده از کیف‌پول» در چک‌اوت، مبلغ کسر نمی‌شد و سفارش با قیمت کامل ثبت می‌شد. هیچ خطای PHP در لاگ دیده نشد.

### علت ریشه‌ای
هوک `woocommerce_cart_calculate_fees` با اولویت پیش‌فرض اجرا می‌شد، در حالی که یک افزونه تخفیف دیگر روی همون سبد با اولویت بالاتر مبلغ رو قفل کرده بود و Fee منفی ما override می‌شد.

### راه‌حل اعمال‌شده
اولویت هوک در `Integrations/WooCommerce/CheckoutWalletGateway.php` از ۱۰ به ۹۹ تغییر کرد تا بعد از سایر افزونه‌های تخفیف اجرا بشه.

### درس گرفته‌شده / پیشگیری آینده
برای هر Fee/Discount که با افزونه‌های دیگر تداخل داره، اولویت هوک باید صراحتاً بالا (اجرای دیرتر) تنظیم بشه و در ARCHITECTURE.md مستند بشه.

### وضعیت
- [x] رفع‌شده
```
